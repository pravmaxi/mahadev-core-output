How to add your own indicator

Open the file and add an entry to the Ind object. It will instantly appear in the “Generic: price vs indicator” dropdown.

Ind.myInd = {
  label: 'My Indicator',
  params: { period: { label:'Period', def:14, min:2, max:300, step:1 } },
  // must return an array of numbers (NaN during warm‑up)
  // or an object of arrays, e.g. { mid:[], upper:[], lower:[] }
  compute(candles, p) {
    const src = candles.map(c => c.c);
    return TA.sma(src, p.period);       // any array works
  },
  // optional: if compute returns an object, list selectable bands
  variants: ['mid','upper','lower']
};

For a fully custom rule, add to the Strategies object instead — see the examples already in the file.
